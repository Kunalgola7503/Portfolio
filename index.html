How I work

Every project follows roughly the same pipeline.

Pull the raw data, understand its quirks, and fix what's broken — missing values, duplicates, inconsistent formats — before any analysis starts. This is usually where most of the real work is.

Look for patterns, outliers, and relationships in the data using statistical summaries and visualizations, to form hypotheses worth testing further.

Where relevant, build regression or classification models and run significance tests — A/B tests, p-values — to confirm findings are real, not noise.

Translate findings into a Power BI or Tableau dashboard with the right measures, filters, and visuals for the people who'll actually use it day to day.

Present the "so what" — clear takeaways and recommendations for stakeholders, not just charts. Data only matters if someone can act on it.
